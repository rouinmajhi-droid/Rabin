## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/DeepakAmalWinstarJ/DeepakAmalWinstarJ_portfolio.git
cd DeepakAmalWinstarJ_portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm start
# or
ng serve --port 4200
```
Navigate to `http://localhost:4200/` in your browser.

### 4. Run tests
```bash
npm test -- --watch=false
```

### 5. Production build
```bash
npm run build
```
Production artifacts will be generated in `dist/deepak-portfolio/browser`.

### 6. Automated Backup
```bash
npm run backup
```
Generates a timestamped, compressed ZIP archive in `backups/`.
